title: "Was kann Agent Copilot?"
---

- 🤖 **Autonomes Coding**: Implementiert Features und behebt Bugs selbstständig
- 🔍 **Code-Verständnis**: Analysiert und navigiert in komplexen Codebasen
- 🧪 **Test-Erstellung**: Schreibt und führt Tests aus, behebt Fehler
- 🔄 **Multi-Step-Aufgaben**: Erledigt mehrstufige Entwicklungsaufgaben
- 📝 **Pull Requests**: Erstellt PRs mit vollständigen Code-Änderungen
- 🛠️ **Tool-Nutzung**: Verwendet Terminal, Browser und Editoren
- 🔒 **Sicherheit**: Überprüft auf Sicherheitslücken im Code
