title: "Was kann Agent Copilot?"
---

GitHub Copilot Agent kann selbstständig komplexe Aufgaben in einem Repository lösen:

- **Code schreiben & refaktorieren** – Neue Funktionen implementieren, vorhandenen Code verbessern
- **Fehler beheben** – Bugs analysieren und Korrekturen vorschlagen
- **Tests erstellen** – Unit- und Integrationstests automatisch generieren
- **Pull Requests öffnen** – Änderungen commiten und direkt einen PR erstellen
- **Repositories erkunden** – Dateien lesen, Strukturen verstehen, Zusammenhänge analysieren
- **Iterativ arbeiten** – Feedback einarbeiten und Änderungen Schritt für Schritt verfeinern
